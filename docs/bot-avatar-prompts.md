# Bot Avatar Generation Prompts

This document contains DALL-E prompts for generating unique chess bot avatars for the Play vs AI feature.

---

## Image Specifications

| Property | Value |
|----------|-------|
| **Dimensions** | 154 × 156 pixels |
| **Format** | PNG with transparency (RGBA) |
| **Shape** | Circular crop |
| **Background** | Neutral gray gradient |
| **File naming** | `lowercase-name.png` |
| **File location** | `/public/images/play-vs-ai/` |

---

## Base Prompt Template

```
portrait of [NAME], [AGE] year old [ETHNICITY] [GENDER], [HAIR], [EYES] eyes, [EXPRESSION], head and shoulders, circular crop, neutral gray gradient background, semi-realistic digital art, stylized 3D render, soft lighting, chess player avatar --ar 1:1 --s 250 --v 6
```
